# Mac ByteSized32 uncertainty diagnostic

This local diagnostic uses the cached native Qwen2.5-0.5B-Instruct checkpoint from the course study at its recorded revision. Run on Mac CPU in float32 with four threads, seed 1729, greedy decoding and a 128-token continuation cap. Keep the original two-model BF16 protocol separate. The 82 private cases and their lossless next-state targets were prepared before model outputs existed. Use every assigned case once. The planned denominator is 37 reversible and 45 irreversible cases over five games. Leave the engine's unknown recovery cases out of analysis.

Use raw logits during cached generation. Average the negative log probabilities of generated content tokens, excluding the prompt and terminal EOS. Before opening the cohort for inference, compare these token scores with a full shifted-logit pass on a synthetic prompt. Benchmark two fixed full-cap synthetic requests at the longest cohort input length or slightly above. Proceed if twice the slowest measured request times 82 fits 20 minutes. Stop under the existing Mac guard for memory pressure, swap, disk or wall time. Preserve failed requests and partial outputs privately. No model download is required.

Report the irreversible-positive AUROC across all cases with finite scores. Also compute the within-game, same-verb AUROC by pooling only opposite-label comparisons within each stratum, weighted by the count of those comparisons. The overlap covers 25 cases across three games. Use whole-game bootstrap resampling with 1,000 draws, seed 9001, and report undefined draws. Include token length and gold changed-object count as descriptive controls. Count strict JSON output, exact delta matches and capped responses separately. Record absent scores and denominators. Generated-sequence NLL measures confidence in the model's own text, including invalid text. It does not measure confidence conditional on a correct state prediction.

Keep raw cases, prompts and outputs outside delivery artifacts. Record aggregate statistics and hashes. Treat small strata, output truncation, terminal-answer actions and repeated game structure as limitations. This run cannot close the original BF16 or joint-environment gates.
